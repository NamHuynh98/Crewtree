# Third-party licenses

Crewtree release bundles redistribute open-source npm packages: the server's and the CLI's production
dependencies (in `server/node_modules`, `cli/node_modules`) and the web UI's dependencies (compiled into
`web/dist`). Each archive contains `THIRD_PARTY_LICENSES.md`, generated by `scripts/pack.mjs` from the
packages actually shipped, with every package's name, version, license and license text.

CI enforces an allow list with `scripts/check-licenses.mjs`: MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause,
ISC, MPL-2.0, 0BSD, CC0-1.0, CC-BY-4.0, BlueOak-1.0.0, Python-2.0, Unlicense, OFL-1.1 (fonts). A dual
license passes when one of its options is allowed.

## Reviewed exceptions

| Package | License | Notes |
|---|---|---|
| `elkjs` | EPL-2.0 OR GPL-3.0-or-later | Used under EPL-2.0, unmodified, compiled into the web UI for the tree layout. EPL-2.0 is a weak, file-level copyleft: the Crewtree code that calls it is not affected. Source: https://github.com/kieler/elkjs |
| `@fontsource-variable/inter`, `@fontsource-variable/jetbrains-mono` | OFL-1.1 | Fonts of the web UI; redistribution with the license text is allowed, the fonts are not sold on their own. |

## Not redistributed

`@anthropic-ai/claude-agent-sdk` and its platform packages (which contain the Claude Code binary) are
proprietary software of Anthropic PBC ("All rights reserved"). They are **not** part of the release
archives: `install.sh`, `install.ps1` and `crewtree update` install the pinned version from the npm registry
on the user's machine, under Anthropic's terms. See `NOTICE`.
